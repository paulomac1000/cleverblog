# Security

This repository contains the source for the deployed cleverblog.pl site.

## Supported scope

Security reports may cover the deployed cleverblog.pl site and this source repository.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Private Vulnerability Reporting once it is enabled.
Do not open public GitHub issues for security reports or vulnerability details.
We aim to acknowledge valid reports within 5 business days.

## Safe disclosure

Do not publish exploit steps, proof-of-concept payloads or other actionable vulnerability details in public issues.
Allow reasonable time for investigation and remediation before public disclosure.
